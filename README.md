# Weather Prediction using RNN

## About
A machine learning project that uses a Recurrent Neural Network (RNN) to predict future weather conditions using historical weather data.

## Dataset
- Dataset: London Weather Dataset
- Source: Provided by μLearn Foundation
- Features include temperature, precipitation, pressure, sunshine and cloud cover.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- TensorFlow / Keras

## Project Workflow
1. Data exploration and preprocessing
2. Feature scaling
3. Time-series sequence creation
4. RNN model development
5. Model training
6. Evaluation using MAE and MSE
7. Actual vs predicted visualization

## Model
Simple Recurrent Neural Network (SimpleRNN).
